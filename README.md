# Smart Desk Hub Enclosure Design

This project is an enclosure for the Smart Desk Hub PCB that I designed for week 1 of Hack Club's Half Life.

The Smart Desk Hub is an ambient smart desktop display station powered by an E-Paper display and an ESP32 microcontroller. It presents time, weather, room metrics, and calendar events at a glance, featuring a dual-tier local/cloud voice assistant for hands-free productivity and task automation.
